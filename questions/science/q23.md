## Which of the following is not an “element + element $\rightarrow$ compound” type reaction ?

---

In $2\text{CO} + \text{O}_2 \rightarrow 2\text{CO}_2$, $\text{CO}$ is a compound reacting with an element ($\text{O}_2$) to form a compound, so it is a 'compound + element $\rightarrow$ compound' reaction.
